# Contributing to PaceLine

Thank you for helping improve PaceLine Local.

Before opening a change, run `npm test`. Keep importers provider-neutral and preserve the canonical activity model: activity, laps, samples, metrics, and source provenance.

Never commit personal FIT/TCX files, provider cookies, access tokens, `.env` files, local databases, or screenshots containing identifiable health/location data. Use synthetic fixtures in `test/` instead.

Open an issue before substantial work so the intended MCP contract and privacy implications can be discussed. Keep provider integrations read-only unless an explicit, audited publish workflow has been designed.
